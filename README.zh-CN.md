# RallySight

**监督对手建模与提前摆位**

我方回球后，RallySight 根据冰球和双方球拍的近期轨迹，预测对手何时触球、球会从哪条线路回来，让球拍提前到位。对手触球后，V4 根据实际观测更新球路，冻结的 J1 继续决定如何击球。

置信门控要求连续两帧预测的落点相近才修改横向目标。短暂缺失时保持已确认目标，并限制目标移动速度。该局最大单帧目标跳变从 **86.61 cm 降到 4.75 cm**，左臂在对手触球前的平均绝对横向速度从 **3.03 降到 0.37 m/s**。总回球少 1 拍，最长连续主动回球从 16 降到 9 拍。

**科研价值。** 保持挥拍模型不变，只改变对手触球前的摆位，能直接验证显式对手预判对高速接触任务的价值。用总回球、连续拍数和摆动幅度同时衡量结果，可以分辨预测变准是否真的让控制更好。

目前的证据来自仿真诊断，包含仿真坐标和接触事件，尚未验证真机或未见对手上的收益。使用 `python scripts/summarize.py` 可按公开轨迹复算指标。本展示不使用 PPO。
